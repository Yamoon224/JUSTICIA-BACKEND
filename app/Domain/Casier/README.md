# Module Casier

Périmètre : cahier des charges §6.10 (Casier judiciaire).

À implémenter en Phase 6 : alimentation automatique par les condamnations
définitives, bulletins B1/B2/B3 avec règles de filtrage paramétrables,
délivrance sécurisée, réhabilitation/amnistie/effacements, contrôle strict
des accès (consultation nominative journalisée et motivée).
